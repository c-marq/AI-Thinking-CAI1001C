# Final Portfolio Rubric
**CAI1001C: AI Thinking | 100 Points Total**

Each row below is one rubric criterion. For Component 1, each criterion is scored holistically across all 3 submitted projects combined. Performance levels: **Excellent** (full points), **Proficient** (~75%), **Developing** (~50%), **Incomplete** (0–25%).
