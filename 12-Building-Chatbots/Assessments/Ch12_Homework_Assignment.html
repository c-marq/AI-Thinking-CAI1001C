Part 1: System Prompt Design (Two Versions)

You'll create two different system prompts for the same business chatbot, then compare how they perform. You can use the same business from your group lab or pick a new one.

Task 1.1: Choose Your Business
Task 1.2: System Prompt — Version A (Basic)

Write a simple system prompt — just the essentials. Keep it to 2–3 sentences. Tell the AI what business it represents and what topics it covers.

Task 1.3: System Prompt — Version B (Detailed)

Write a detailed system prompt — at least 5–6 sentences. Include: specific business facts (hours, prices, location), tone/personality instructions, what to do with unknown questions, and any boundaries (e.g., "Don't make up prices").

Part 3: Comparison & Analysis

Task 3.1: Version Comparison

Which version performed better overall? Consider: accuracy on standard inputs, handling of edge cases, tone, and hallucination (making things up). Write 3–4 sentences.

Task 3.2: Hallucination Check

Did either version make up information that wasn't in your system prompt (e.g., inventing prices, hours, or policies)? Which version hallucinated more? Why do you think that happened?

Task 3.3: Connect to the GP — System Prompts vs. Python Code

In the GP demo, you built a chatbot with Python dictionaries, keyword matching, and if/elif logic. In this homework, you built one with a system prompt and an LLM. Compare the two approaches. Which gives you more control? Which handles unexpected inputs better? Which is more likely to hallucinate? Write 3–4 sentences.

Part 4: Ethics Reflection

⚖️ Reflect & Discuss: Address one of the following prompts in at least one full paragraph (minimum 4–5 sentences).
  1. You just built a chatbot. At what point in a conversation should the chatbot disclose that it's not human? At the start? Only if asked? Never?
  2. A mental health support chatbot helps people in crisis at 3am when no humans are available. But it doesn't disclose that it's AI. Is this ethical? Does the benefit outweigh the deception?
  3. Design a disclosure policy for a chatbot at a business you care about. What would it say, when would it say it, and why?
