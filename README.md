# AI Thinking: CAI1001C

**Miami Dade College | Professor Carlos Marquez**

A hands-on introduction to artificial intelligence where students explore AI technologies, build machine learning models using Python, and analyze the ethical implications of AI systems.

**No prior programming experience required.**

---

## Getting Started

All projects run in Google Colab (free, cloud-based Python).

1. Go to [colab.research.google.com](https://colab.research.google.com/)
2. Sign in with your Google account
3. Test it: File → New Notebook → Type `print("Hello AI!")` → Run cell

To open notebooks in Colab from this repo: in Colab, choose File → Open Notebook → GitHub tab → enter the repo URL → navigate to the notebook you want.
