Task 1: Sentiment Analysis on HuggingFace (5 min)
Setup

Go to: huggingface.co/distilbert/distilbert-base-uncased-finetuned-sst-2-english

Find the Inference API widget on the right side of the page. You'll see a text box where you can type input.

Do This

Type each of the following reviews into the Inference API widget and record the result:

Review Label (POSITIVE/NEGATIVE) Confidence % Correct?
The food was amazing and the staff was friendly.
Worst dining experience of my life. Never coming back.
It was okay I guess. Not great, not terrible.
Connection to Chapter: This is the same model (distilbert) we used in the GP demo Part 2. Did the results here match what you saw in Colab? (1-2 sentences)
Task 2: Compare a Different Sentiment Model (5 min)
Setup

Go to: huggingface.co/nlptown/bert-base-multilingual-uncased-sentiment

This model returns star ratings (1-5) instead of just POSITIVE/NEGATIVE.

Do This

Type the same 3 reviews from Task 1 and record the star ratings:

Review Star Rating Does this match the Task 1 result?
The food was amazing and the staff was friendly.
Worst dining experience of my life. Never coming back.
It was okay I guess. Not great, not terrible.
Connection to Chapter: The first model gives POSITIVE/NEGATIVE. This model gives 1-5 stars. Which approach gives you more useful information about a customer's experience? Why? (2-3 sentences)
Task 3: Machine Translation (5 min)
Setup

Go to: huggingface.co/Helsinki-NLP/opus-mt-es-en

This model translates Spanish → English.

Do This

Type each Spanish sentence and record the English translation:

Spanish Input English Translation Quality (Good/Okay/Bad)
La comida estuvo deliciosa y el servicio fue excelente.
No me gustó la comida, estaba muy salada.
Dale bro, la comida estaba brutal y el ambiente chevere.
Connection to Chapter: The third sentence uses informal Spanish with slang. How well did the model handle it compared to the formal sentences? Why might this happen? (2-3 sentences)
Task 4: The Bias Test — Your Own Pairs (5 min)
Setup

Go back to: huggingface.co/distilbert/distilbert-base-uncased-finetuned-sst-2-english

Do This

As a group, write 2 pairs of reviews. Each pair should express the same sentiment — one in formal English, one in Spanglish, slang, or informal language. Test both versions and record results:

Pair 1:

Version Your Review Label Confidence Match?
Formal
Informal

Pair 2:

Version Your Review Label Confidence Match?
Formal
Informal
Connection to Chapter: Did you find any label mismatches — same sentiment, different classification? If yes, why do you think the model got confused? If no, what made your informal version different from the Spanglish examples in the GP demo? (2-3 sentences)
Task 5: Group Discussion (5 min)
Discuss as a group and write your consensus answers:

1. If a Miami restaurant used one of these sentiment models to automatically sort customer reviews, which model would you recommend — the POSITIVE/NEGATIVE one (Task 1) or the star-rating one (Task 2)? Why?

2. Based on what you saw in Tasks 3 and 4, what's one thing AI companies should do before releasing an NLP model for public use?
